# BALKAN26

Мобильный семейный путеводитель по Албании и Северной Македонии, подготовленный для GitHub Pages.

## Как обновлять поездку

Русские данные остановок находятся в `trip-data.js`, дополнительные дорожные остановки и шопинг — в `extras.js`, английский слой — в `trip-data-en.js`, а текущий снимок прогноза — в `weather-forecast.js`. Структура каждой остановки одинакова, поэтому новые места можно добавлять копированием соседнего блока. При изменении текста обновляйте обе языковые версии.

`index.html`, `styles.css` и `app.js` отвечают за внешний вид и поведение; для обычного обновления маршрута их менять не требуется.

## Локальный просмотр

Можно просто открыть `index.html` в браузере. Для проверки поведения GitHub Pages удобнее запустить любой локальный статический сервер в корне проекта.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **GitHub Actions**.
4. Workflow из `.github/workflows/pages.yml` автоматически опубликует сайт после отправки изменений в ветку `main`.

Текущий прогноз получен из Open-Meteo 13 августа 2026 года. Во время поездки обновляйте `weather-forecast.js` каждые 2–3 дня и обязательно перепроверяйте горные и морские условия утром перед активностью.

Рейтинги Google Maps меняются. В текущей версии проверенные оценки датированы 9 августа 2026 года; отметка «проверить Google» означает, что надёжно подтвердить оценку не удалось.
